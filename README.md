# Repository Guidelines
---

### Files That Should Not Be Uploaded

To keep the repository lightweight and maintainable, avoid uploading:

* Large `.exe` installers
* Generated `.log` files
* Temporary files
* Build artifacts
* Virtual machine images
* Large datasets
* Credentials or API keys
* Passwords or authentication tokens
* Personal or private documents

### Examples

```text
*.log
*.exe
*.tmp
*.iso
*.vmdk
.env
```

# Contributing

If you are an NFSU student and want to contribute useful academic material:

1. Fork the repository.
2. Create a separate branch.
3. Add the material under the appropriate semester and subject.
4. Use clear and descriptive filenames.
5. Create a Pull Request with a short description of your contribution.
6. Do not upload personal information, credentials, or sensitive data.

### Example

```bash
git clone https://github.com/AasthaThakker/MSc-Cyber-Security-Material---Aastha-Thakker---GNR-Campus.git
cd MSc-Cyber-Security-Material---Aastha-Thakker---GNR-Campus
git checkout -b add-new-material
```

After adding your material:

```bash
git add .
git commit -m "Add IoT Unit 2 material"
git push origin add-new-material
```

Then create a Pull Request on GitHub.
